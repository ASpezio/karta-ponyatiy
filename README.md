# Карта понятий школьной программы

Интерактивный 3D-граф понятий: история 5–11 классов и физика 7–11 классов (3 477 понятий).

Открыть: https://aspezio.github.io/karta-ponyatiy/

Управление: тянуть мышью — вращать, Shift + тянуть — сдвигать, колесо — приблизить, щелчок по точке — её связи, пробел — фильм.
